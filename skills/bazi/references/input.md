# 输入与时间约定

## 自然语言收集

出生排盘需要：出生日期、公历或农历、时分、出生地点、当时使用的钟表时间和排盘口径。起运另需传统算法使用的男/女参数，不从姓名、语气或职业猜测。只问旺衰或只排四柱不用强求性别。只给农历时须确认闰月并保留换算出处，程序不接受把农历数字直接当公历。

课程推荐真太阳时与 23 点换日（B01）。用户未选时间口径时说明可按当地真太阳时，或按其明确选择的标准时间。程序不自动根据城市猜经度，不把经度每度四分钟的平太阳时差冒充真太阳时的全部修正。真太阳时输入应有可信排盘工具/历算来源，说明出生地点和换算口径。不存在可信换算结果时先问用户口径或沿用其原盘。

出生时间有误差且跨时辰、23 点/零点或节气时刻时，按误差范围比较候选盘，只对稳定部分作主判断。未知时辰不假定中午；若能可靠得到前三柱，可用手动模式。所有未知项保留。

## 出生模式 JSON

```json
{
  "question": "比较 2026 与 2027 年的工作与收入趋势",
  "mode": "birth",
  "birth": {
    "datetime": "1990-05-17T10:30:00+09:00",
    "place": "北京；出生记录为当时夏令钟表时间，UTC+09:00 已确认",
    "basis": "standard_utc8"
  },
  "day_boundary": "zi23",
  "gender": "male",
  "flow_years": [2026, 2027]
}
```

以上是格式示例，不能当用户实际出生资料。`datetime` 必须是含时区偏移的公历 ISO 日期时分，可含秒。程序将其转换为固定 UTC+08:00；上例对应 09:30 标准时间。UTC 偏移本身已反映夏令时，不能再减一次。历史夏令时具体日期、重复/不存在的钟表时刻须先核对，不按“1986—1991 全年都减一小时”处理。程序不根据 `place` 自动验证偏移。

- `basis=standard_utc8`：年、月、日、时都以转换后的北京时间标准钟面计算。海外出生仅在用户明确要求这个口径时使用，不宣称等同其当地民用时。
- `basis=provided_true_solar`：另加 `solar_datetime`（无时区 ISO 字符串，如 `2000-06-01T11:42:00`）及 `solar_source`。年/月柱、交节间隔和起运用出生的真实瞬间；日/时柱用已核实的真太阳钟面。程序不复核天文换算结果。
- `day_boundary=zi23` 默认：23:00 换日；`midnight`：00:00 换日，晚子时的时干按未换日的日干推。这是明确的工程口径，不声称涵盖所有“早晚子时”派法。
- `gender` 可省略；省略则 `yun=null`。`male/female` 仅供传统阳男阴女顺、阴男阳女逆算法使用。
- `flow_years` 可省略，最多 30 个 1901—2098 年；表示该公历年份立春起至下一立春的干支年，绝非元旦到年末。
- 自动出生年份范围 1901—2099；拒绝未知字段，防止忽略用户指定的时间或算法。

## 手动模式 JSON

```json
{
  "question": "解释前三柱的日主旺衰",
  "mode": "manual",
  "pillars": ["甲子", "丙寅", "甲子", null],
  "source": "用户提供原盘，时柱未知"
}
```

按年/月/日/时排列；前三柱必须有效，只有时柱可为 `null`。检查六十甲子合法性、五虎遁以及有时柱时的五鼠遁。不能从四柱反推一个出生日期并据此排运；该模式不接受出生字段和性别，也不自动推算起运。原盘采用不同晚子时规则导致检查失败时，保留原盘说明差异，不能修改原盘使其通过。

手动模式的 `day_boundary` 不重排四柱；程序明确标记沿用原盘。用户提供的大运可另附在分析记录中，注明来源和交运日期，不能冒充程序重新计算的结果。

## 输出与保存

`pillars` 包括藏干十神、日主临各支十二长生、各柱自坐十二长生、得令状态、根气事实及旬空。`roots` 含所有已知支的同五行藏干，不宣称跨柱即可同等有力；`same_stem` 区分同干与同五行，`main_qi` 只标本气，不预设其余藏干权重。

`month_hidden_candidates` 仅列透出，不定格；日干自身出现不等于另有一个可用格神。`yun.dayun` 的区间左闭右开，以精确起运时刻每十个公历年推进，是本版工程约定；起运换算只精确到历法库分钟粒度，不能当现实事件的精确应期。

使用新输出目录保存原输入、机器 JSON 与 Markdown。分析另存 `analysis.md`。输入有用户文字时写文件，不拼可执行命令。
